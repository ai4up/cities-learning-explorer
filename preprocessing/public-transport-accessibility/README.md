# Public transport accessibility one-off preprocessing

This folder archives the one-off preprocessing artifacts used to add SDG 11.2.1
(urban access to public transport) into the explorer dataset.

Included artifacts:
- `city-mapping-SDG-PT-2026-05-19.ipynb`: matching workflow notebook.

The matched CSV (`cities_with_pt_access.csv`) is intentionally **not** stored in
the repository because its integrated values are already persisted in
`public/cities.json`.

Primary source citation:
- Center For International Earth Science Information Network (CIESIN), Columbia University (2023).
  *SDG Indicator 11.2.1: Urban Access to Public Transport, 2023 Release*.
  https://doi.org/10.7927/1A5Z-3H71
